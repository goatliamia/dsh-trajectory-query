# Trajectory Tree 视觉语言与资产

本文件记录面板、路径、上下文及诊断报告共享的视觉含义。面向实现和维护，不随模型的分析 skill 默认加载。浅色令牌的唯一声明是 [tokens.mjs](tokens.mjs)；[tokens.css](tokens.css) 和 [样张页](index.html) 由 `node scripts/build-design-assets.mjs` 生成。

## 来源与取舍

参考 Vercel 官方 [Geist Colors](https://vercel.com/geist/colors)、[Typography](https://vercel.com/geist/typography)、[Materials](https://vercel.com/geist/materials)：中性页面、按用途分配颜色、正文与标签的文字层级、按层级使用圆角/边框/阴影。Geist 的基础材料使用 6px 圆角，浮动菜单和模态使用 12px；本项目将它们收敛成控件 6px、浮层 12px。图表和正文主要通过留白及细分隔线组织。

上下文来源色、图形结构、动效和报告组件由本项目定义。沿用原面板最终生效的 `--chart-*` 色值。`context-model.mjs` 内的历史默认数组会被 Geist 层覆盖，不能将其当作最终主题色表。

## 七类来源固定对应

| key | 含义 | 浅色颜色 |
|---|---|---|
| system | 系统提示 | `#8053e3` |
| tools | 工具说明与参数定义 | `#d49b00` |
| user | 用户消息 | `#44a56b` |
| inject | 环境、状态、通知等补充内容 | `#c442a7` |
| skill | 通过技能来源进入上下文的内容 | `#e66d26` |
| assistant | 助手消息，包括保留的工具调用 | `#5b9fe8` |
| tool | 工具返回内容 | `#3ab4a4` |

同一 key 在构成、趋势、拼装和证据图例中使用同一基色；来源标签使用同一名称。来源色不表示成功、失败或内容价值。缺失分类显示中性灰及“未分类”，不自动生成第八种来源含义。

源条、环形扇区、堆叠条和图例使用实色。趋势面积可以采用固定的弱填充，同时保留实色轮廓；降低透明度只表达面积背景或明确的未选中状态。不能在片段、父组、容器上重复叠加透明度，造成基色漂移。

## 来源、状态与计量分开

| 用途 | 颜色 / 表达 |
|---|---|
| 已确认完成 | `#087b58`，完成符号 |
| 实际失败 | `#c72b31`，错误符号 |
| 重试 | `#8745d9`，回转符号 |
| 结构变化 / 压缩 | `#b87800`，替换或压缩标记 |
| 操作与证据链接 | `#0068d6` |
| 常规数值系列 | `#3485ed`，清晰的计量蓝，不隐含某种上下文来源 |
| 缓存读取 / 未缓存输入 / 缓存写入 / 输出 | `#3485ed` / `#f59a36` / `#9561dd` / `#1aaa91`，必须有各自的桶标签 |

“工具结果”青绿色不代表工具执行成功；“助手消息”蓝色不自动用于全部指标。计量图使用自己的列名、图例和单位；token 比例与费用比例分别说明。

数值图不使用整片灰蓝；输入桶采用明快的蓝、橙、紫、青，正文保持深色，辅助文字才使用灰色。报告以计量蓝标记章节编号与关键读数，浅蓝底仅用于主要判断，不为每一节添加色框。七类上下文来源和执行状态的对应关系保持独立。

历史替换可能是正常整理。拼装时保留来源条的基色，用短暂红色描边及离场碎片定位旧片段；它是过渡提示，不把这轮标成执行失败。变化完成后恢复普通状态。

## 基础样式

- 页面白色 `#fff`，次级底 `#fafafa`，正文 `#171717`，次级文字 `#666`，分隔 `#e6e6e6`，网格 `#ededed`。
- Geist 用于正文与标签，Geist Mono 用于数字、位置与代码。中文回退到系统字体。正文 14px，标签 12px，辅助 11px；报告标题 28px、章节 18px、关键数值 28px。SVG 使用 viewBox 坐标，实际可读性仍需在页面尺寸上判断。
- 间距使用 4 / 8 / 12 / 16 / 24 / 32 / 40px。普通文章最大 1040px；诊断报告最大 1280px、两侧 32px，窄屏 22px。章节标题与正文起点对齐，目录按需展开；只在正文宽度足够时分栏，不为短标题或少量目录项保留整页空列。
- 图表平铺在正文中，使用分隔与标题明确范围。控件使用 6px 圆角；浮层使用 12px、1px 边框与轻阴影。浮层层级同时由定位、边框和焦点状态说明。
- 选中来源使用实心点，取消使用空心点。选中状态同时有文字、边框或形状提示；错误不只靠红色识别。
- 普通报告先呈现静态结果。拼装的播放由读者控制，切页/离屏暂停；减少动态效果模式不自动播放。

## 可复用资产

| 资产 | 用途 |
|---|---|
| [tokens.mjs](tokens.mjs) | 来源、状态、输入桶、字体、间距和动效的程序接口 |
| [tokens.css](tokens.css) | 生成的 `--tt-*` CSS 自定义属性 |
| [primitives.css](primitives.css) | 文字、指标、分隔、按钮、来源点选、证据链接和浮层基础类 |
| [icons.svg](icons.svg) | 本地绘制的完成、错误、重试、替换与证据符号 |
| [index.html](index.html) | 可直接打开对照的颜色、字体、材料与交互样张 |
| [Geist 字体目录](../plugin/analysis-view/lib/trace/fonts/) | 已有的本地 woff2；许可证见 [OFL](../docs/demo/layout-review/fonts/LICENSE.txt) |

报告和拼装组件直接消费共享令牌。原生路径、独立趋势及 Pi/Codex 页面构建器已接入同一浅色覆盖；现有运行中的 DSH 未因本次整理重新安装。旧图的暗色主题继续沿原实现，尚未作为这份浅色资产的完整迁移结果。

新增组件先选择已有来源/状态/数值角色，再复用基础类。模型提交来源 key、字段、重点和顺序，渲染器决定颜色、字体及间距。正式报告的长文组合和少量复合版式还需用完整报告检验，不能只凭单图样张认为已经完成。
