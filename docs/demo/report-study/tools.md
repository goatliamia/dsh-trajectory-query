# {{topTool}} 返回了最多内容，先看它取回了什么

在这段插件开发对话里，**{{topTool}}** 的返回文本约 **{{topChars}} 字符**，占已记录工具返回文本的 **{{share}}%**。把规模与调用次数放在一起，可以选择值得继续展开的工具。

[[figure:tools]]

## 这张图帮助选择什么

从返回最多的工具进入具体调用，区分查代码、读日志、跑检查和生成产物。工具名字相同，承担的工作可能很不一样，返回规模只是选择阅读对象的起点。

## 怎样形成具体改法

结合相应任务检查读取范围、重复内容和后续采用，再提出可复现的调整。保留工具原有能力、完整参数和正文入口，用实际输入与补读检验改法。
