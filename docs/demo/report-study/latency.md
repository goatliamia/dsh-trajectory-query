## 这张图帮助选择什么

不用从头翻完整段对话，也不用把所有步骤都当成同一种等待。先选耗时较长的区间，进入里面的具体轮次，再沿调用和反馈继续读。

## 怎样继续诊断

将长步骤放回当时的任务：必要的构建和校验值得保留，重复确认、失败恢复和阻塞则分别处理。改法最终落在这些步骤承担的工作上。
