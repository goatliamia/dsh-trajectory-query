## 为什么不能只看会话平均值

会话整体的缓存读取比例会掩盖少量高未缓存输入请求。按具体请求展开后，才能继续检查当时的模型、工具定义、材料注入和上下文前缀发生了什么变化。

## 下一步怎样用

从这些请求读取实际上下文及前后变化，选择值得检查的缓存边界。图中是输入 token 的构成，费用还需要结合对应模型的计价；保留工具能力和使用场景，再评估配置是否值得调整。
