## 当前图形规则

- 一条横向主干覆盖全部轮次。轮内保持同一线性时间比例，轮间等待用 // 折叠；全览的事件标记锚定真实发生位置，放大展开原始步骤和调用区间。
- 全部错误可见，不挑选三个代表。标签和枝条在上下空位避让，独立子 Agent 的空间参与预留，不移动事件时间位置容纳文字。
- 同一步同工具同结果可以汇总数量。真实调用区间有重叠时展开并行细枝；串行批次保持单枝。工具条长度为真实时间，名称在附近单独排布。
- 文件前置条件拦截用截口，超时用时钟，其他显式调用错误用叉；固定文案、形态与颜色共同表达状态。
- 只给失败调用自身的时间区间着红。失败至原操作再次成功之间的处理经过时间不画成失败耗时。
- 本轮完整参数相同的原操作随后成功时，用带成功端的虚线关联；覆盖全部目标的成功读取发生在对应重做之前时显示“补读后”。缺少后续同参成功仅表示未知，不推断任务失败。
- 子 Agent 从委派位置长出副枝，内部保留请求与工具活动。结束使用子会话真实结束时间；回传使用有发送方 Session 身份的消息实际送达时间，不把运行结束通知当作业务结果或采用证据。
- 模型请求重试用请求上的 ↻ 角标；停止与中断用主干双竖线；压缩用原位刻痕，没有独立泳道。
- 保留滚轮缩放、左右拖动和全览复位。点击错误事件聚焦实际处理区间；调用、接续和子任务可查看原记录。固定滚动条预留空间，避免缩放时焦点漂移。
