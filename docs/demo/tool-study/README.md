# 工具行为与枝条视觉试作

独立网页，未接入 DSH。沿用 Geist 字体、中性底色、细线与固定工具语义色，展示真实会话的外层工具和 Code Mode 内部 dispatch；有内部工具时折叠包装层，纯代码调用仍保留。

```powershell
node scripts/build-original-tool-study.mjs
node scripts/serve-tool-study.mjs 3086
```

打开 `http://127.0.0.1:3086/`。首页直接复用原图模板、CSS、渲染器与交互，只注入工具行为补充；不增加卡片框、不替换原图配色。生成数据仅保存到 Git 忽略目录 `.dsh/tool-study/`；网页不访问 DSH API、不发送消息，也不修改会话或安装配置。字体均从本地提供。

- 默认打开原有 455 轮全景，可切换搜索与读取、命令与修改的真实轮次，以及任意轮次。`?turn=113` 可直接进入混合操作行动路径。
- 枝条使用同一套 16 单位线图标，类别色表达工具行为，小状态点表达已返回、错误或尚无返回。
- grep 仅把实际返回匹配行的路径关联为“搜索命中片段”；read 的读取窗口单独记数。glob 与搜索目录不算文件内容读取。
- 汇总分支可展开具体工具；参数、返回原文和事件依据都在右侧详情内。预览保留有界原文节选并标注省略量。
- 总览按连续轮次聚合；逐轮图按步骤顺序排列，间距不代表耗时。完整起止时间仍从原事件读取。

语义验证：`node docs/demo/tool-study/model-test.mjs`。
