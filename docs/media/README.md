# README 展示素材

素材由项目现有路径、趋势、装配和报告渲染器生成，输入全部为合成示例；不读取本地真实会话。

运行 `node scripts/build-readme-media.mjs --serve 3099`，分别打开 `/path`、`/context`、`/assembly` 和 `/report` 可重现截图页面。截图与短动图仅展示已有界面，不替代实际运行数据。

- `trajectory-overview.jpg`：执行路径与上下文来源点选。
- `context-trend.jpg`：保留量和增量趋势组件。
- `context-assembly.gif`：逐轮装配与历史改写的概念序列。
- `diagnostic-report.jpg`：示例报告，使用现有报告模板与组件。
